# MvFFN project page

Static project page for **MvFFN: Multi-view Floor Plan Feed-Forward Network for Unposed Wide-Baseline Panorama Layout Reconstruction**.

Open `index.html` directly, or serve the repository root locally:

```bash
python -m http.server 8000
```

The page content and figures are derived from the NeurIPS 2026 camera-ready paper. The layout follows the academic project-page structure used by the BADGR/Nerfies template, without its analytics or JavaScript dependencies.
